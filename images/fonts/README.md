# Greeting font

`DancingScript-Bold.ttf` is the existing 700-weight Dancing Script typeface,
bundled locally so the greeting and its pen masks use the same lettering even
when external font services are unavailable.

Source: https://fonts.googleapis.com/css2?family=Dancing+Script:wght@700

Font binary: https://fonts.gstatic.com/s/dancingscript/v29/If2cXTr6YS-zF4S-kcSWSVi_sxjsohD9F50Ruu7B1i0HTQ.ttf
